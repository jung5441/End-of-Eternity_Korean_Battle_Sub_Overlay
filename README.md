# Resonance of Fate 전투 대사 한글 자막

PC판 **Resonance of Fate 4K/HD Edition**의 전투 음성에 한글 자막과 화자 이름을 표시하는 비공식 오버레이입니다.

게임 본편의 메뉴나 스토리 대사를 번역하는 한글패치가 아닙니다. 전투 중 재생되는 음성을 감지해 화면 상단 중앙에 별도의 한글 자막을 표시합니다.

현재 배포중인 한글패치와는 호환이 안될 수 있습니다. 테스트 하지 않았습니다.

## 주요 기능

- 전투 대사를 PNG 이미지가 아닌 선명한 텍스트로 표시
- 자막을 화면 상단 중앙에 배치
- 아군 화자 이름을 하늘색으로 표시
- 적 화자 이름을 빨간색으로 표시
- 실제 전투 객체를 확인해 적 이름 자동 연결
- 여러 인물이 동시에 말할 때 자막 동시 표시
- 일본어·영어 음성의 자막 표시 시간 선택
- 게임 EXE 경로 저장
- 자막 도구에서 게임 자동 실행 및 연결
- 테두리 없는 전체 창모드 지원
- Steam을 통한 느린 게임 실행 대기
- 스트레이독의 울음이 사람 대사로 표시되던 오류 수정

## 지원 범위

- 전체 음성 목록: 2,456개
- 현재 자막이 연결된 음성: 2,038개
- 자동 연결되는 적 이름: 223개
- 네이티브 전투 대사 텍스트 변환: 1,010개

일부 자막은 음성 인식에 기반한 초안입니다. 모든 음성의 의미와 화자 연결이 완전히 검증된 상태는 아닙니다.

## 지원 게임

- Steam판 `Resonance of Fate 4K/HD Edition`
- 실행파일 이름: `Resonance of Fate.exe`
- 제작 과정에서 검증한 실행파일 SHA-256:

```text
49c9e7f5a46a92e2ebbf3d37f11ec26493b05d3c9f0dccf6668011a8149ec1eb
```

게임 업데이트나 다른 패치가 실행파일을 수정한 경우 연결되지 않을 수 있습니다. 게임 데이터만 변경하고 실행파일을 수정하지 않는 한글패치는 함께 작동할 가능성이 있지만, 모든 패치와의 호환성을 보장하지 않습니다.

## 사용 방법

1. 게임의 그래픽 설정을 **창모드**로 지정합니다.
2. 전투 자막 실행파일을 실행합니다.
3. 처음 실행할 때 **게임 EXE 선택**을 누릅니다.
4. Steam 게임 폴더의 `Resonance of Fate.exe`를 선택합니다.
5. **게임 실행·자막 연결**을 누릅니다.
6. 일본어 또는 영어 음성 길이를 선택합니다.

게임 경로와 옵션은 저장됩니다. 자동 실행 옵션을 켜 두면 다음부터는 전투 자막 도구만 실행해도 게임 실행과 자막 연결을 자동으로 시도합니다.

## Steam 실행 대기

Steam을 거쳐 게임이 실행되면 실제 게임 창이 나타날 때까지 시간이 걸릴 수 있습니다.

도구는 다음 방식으로 기다립니다.

- 게임 실행을 최대 5분 동안 대기
- 같은 게임 창이 3초 이상 유지된 후 연결
- 게임이 시작 과정에서 창을 다시 만들면 계속 대기
- 전체 창모드 적용이 늦어져도 자막 연결을 유지하고 재시도

대기 중에는 도구를 종료하거나 **연결 해제**를 누르지 마세요.

## 테두리 없는 전체 창모드

이 기능은 게임의 창 테두리를 제거하고 현재 모니터 크기에 맞추는 방식입니다.

게임 설정에서 처음 한 번은 반드시 **창모드**를 선택해야 합니다. 게임의 독점 전체화면 설정을 직접 변경하는 기능은 아닙니다.

연결을 해제하거나 자막 도구를 정상 종료하면 원래 창 크기와 위치를 복원합니다. 도구를 강제 종료해 복원되지 않았다면 게임을 다시 실행하세요.

## 자막 색상

- 아군 화자: 하늘색
- 적 화자: 빨간색
- 대사: 흰색
- 자막 배경: 검은색

적 이름은 음성 번호만으로 추측하지 않습니다. 현재 전투에 존재하는 실제 적 객체와 게임의 적 이름 데이터를 확인해 연결합니다.

## 설정 파일

게임 경로와 실행 옵션은 다음 위치에 저장됩니다.

```text
%LOCALAPPDATA%\EternityBattleSubtitles\launcher.json
```

게임 설치 폴더를 옮겼다면 전투 자막 도구에서 EXE를 다시 선택하세요.

자막 실행 기록은 실행 데이터 폴더의 `logs` 폴더에 저장됩니다.

## 문제 해결

### 지원하지 않는 게임 버전이라고 나옵니다

게임 실행파일의 해시가 지원 대상과 다릅니다.

가능한 원인:

- 게임이 업데이트됨
- 다른 한글패치가 EXE를 수정함
- 실행파일 개조나 모드가 적용됨
- 잘못된 EXE를 선택함

Steam 파일 검사를 진행하면 실행파일이 원본으로 복원될 수 있습니다. 다른 패치가 필요한 경우에는 먼저 해당 패치가 EXE를 수정하는지 확인하세요.

### 게임 창을 찾지 못합니다

- Steam과 게임의 실행이 끝날 때까지 기다려 주세요.
- 게임이 실제로 실행됐는지 확인해 주세요.
- 저장한 EXE 경로가 현재 게임 설치 경로와 같은지 확인하세요.
- 게임을 관리자 권한으로 실행했다면 자막 도구도 같은 권한으로 실행해야 할 수 있습니다.

### 자막이 보이지 않습니다

- 자막 도구에 연결 완료 메시지가 있는지 확인하세요.
- 게임이 최소화되지 않았는지 확인하세요.
- 게임이 현재 활성 창인지 확인하세요.
- 게임의 음성 언어와 도구의 음성 길이 설정을 맞춰 주세요.
- 독점 전체화면 대신 창모드와 테두리 없는 전체 창모드를 사용하세요.

### 전체 창모드가 바로 적용되지 않습니다

게임이 시작 과정에서 창 크기를 다시 설정할 수 있습니다. 도구가 이를 감지하면 자동으로 전체 창모드를 다시 적용합니다.

계속 창모드로 남는 경우 연결을 끊지 말고 잠시 기다려 주세요.

### 화자 이름이 표시되지 않습니다

모든 적 이름이 연결된 것은 아닙니다. 현재 223개 이름이 연결돼 있습니다.

이름을 안전하게 확인할 수 없거나 전투 객체가 전환 중인 경우에는 잘못된 이름을 표시하지 않기 위해 이름을 생략할 수 있습니다.

### 엉뚱한 대사가 표시됩니다

다음 정보를 오류 제보에 포함해 주세요.

- 화면 캡처
- 해당 전투와 적 이름
- 사용한 음성 언어
- 표시된 잘못된 대사
- 자막 도구의 `logs` 파일
- 사용한 게임 EXE의 SHA-256

## 알려진 제한 사항

- 일부 음성은 아직 자막이 없습니다.
- 일부 음성 인식 기반 대사는 오역이나 오인식이 있을 수 있습니다.
- 적 이름 256개 중 223개가 현재 연결돼 있습니다.
- 다른 패치가 게임 EXE나 음성 처리 코드를 바꾸면 작동하지 않을 수 있습니다.
- 독점 전체화면에서는 외부 오버레이가 표시되지 않을 수 있습니다.
- 관리자 권한이 다른 두 프로세스 사이에서는 연결이 실패할 수 있습니다.
- 실제 게임의 모든 전투 장면을 검증한 것은 아닙니다.

## 배포 파일에 대하여

이 저장소와 배포 파일에는 게임 본체나 PS4 게임 데이터, 음성 파일을 포함하면 안 됩니다.

배포할 수 있는 항목:

- 직접 작성한 전투 자막 도구
- 직접 작성한 코드와 문서
- 한글 자막 데이터
- 실행에 필요한 자체 제작 설정 파일

배포하면 안 되는 항목:

- 게임 실행파일
- 게임 아카이브
- PS4 PKG 또는 추출 데이터
- 원본 음성 파일
- 원본 게임 이미지나 글꼴 파일

게임과 필요한 원본 데이터는 사용자가 직접 준비해야 합니다.
